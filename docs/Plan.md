# Dataify 首版计划

## 目标

**每天积累数据，通过 MCP 向 AI 提供可追溯的历史变化，支持内容选题和海外市场研究。**

## 小红书：内容研究与选题

| 能力 | AI 获得的数据 |
|---|---|
| 内容搜索 | 按关键词、发布时间查找已采集内容，获取已记录的互动数据 |
| 热门内容 | 采集范围内互动较高的内容，以及同一内容的互动增量 |
| 热门关键词 | 跟踪词的互动表现、历史变化和对应内容 |
| 增长关键词 | 可比周期内增长较快的跟踪词、增量和对应内容 |

先交付内容搜索、热门内容；关键词榜单在采样和比较口径验证后开放。

**预期效果**：积累足够记录后，AI 能回答“已跟踪的露营内容中，近 7 天哪些互动增长较多”，并引用具体内容和前后数据。

### 首批分类与关键词

**6 个分类，每类 5 个关键词，共 30 个。**

| 分类 | 关键词 |
|---|---|
| 美妆个护 | 护肤、彩妆、洗护、防晒、香水 |
| 服饰穿搭 | 穿搭、女装、鞋子、包包、配饰 |
| 美食饮品 | 美食、咖啡、烘焙、茶饮、零食 |
| 母婴育儿 | 母婴、育儿、辅食、孕期、早教 |
| 家居家装 | 装修、家居、收纳、家具、家电 |
| 运动户外 | 健身、跑步、徒步、露营、骑行 |

围绕这 30 个词每日采集，并持续更新已跟踪内容的互动数据。分类用于组织关键词，内容可关联多个词，无需逐篇人工或 AI 分类。

## 亚马逊：海外市场与营销研究

作为扩展方向，先确认 API 可提供的数据，再确定首批站点和品类。

| 能力 | AI 获得的数据 |
|---|---|
| 商品搜索 | 商品信息及已记录的历史价格、卖点 |
| 竞品对比 | 同站点、同类商品的价格、榜单位置、评分和评价数量 |
| 用户反馈 | 带时间的评价及对应商品 |
| 市场变化 | 同一商品的价格、榜单位置和评价数量变化 |

**预期效果**：AI 能回答“已跟踪的美国站露营灯近一个月哪些调价、排名如何变化、出现了哪些新反馈”，并引用历史记录。

## 交付标准

- AI 可通过 MCP 查询数据，获取来源、采集时间和覆盖范围。
- 每日更新保留历史，能比较同一对象在不同日期的数值与增量。
- 历史从采集开始积累；缺失记录明确说明，不当作零值。
- 排名和增长仅代表可比的采集样本；搜索返回条数不当作全平台热度，榜单位置不当作销量。
