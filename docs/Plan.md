# Dataify 数据能力：需求与预期效果

## 目标

**持续积累内容与市场的历史数据，让 AI 能够回答：过去怎样、现在怎样、何时发生变化、变化是否持续。**

数据中心的核心价值是保留时间上的变化：既能回看指定日期的已知状态，也能比较同一对象在不同周期的表现，为内容策划和海外营销提供可追溯的趋势依据。

## 小红书：内容研究与选题

| 能力 | AI 获得什么 | 支持什么任务 |
|---|---|---|
| 内容搜索 | 指定主题和历史时期的内容，以及已有的互动变化记录 | 回看过去的内容表现，比较不同阶段 |
| 热门内容 | 各期热门内容及同一内容的互动走势 | 区分长期热门、近期增长和热度回落 |
| 热门关键词 | 各期热门主题、关联内容及变化轨迹 | 观察主题更替，研究重复出现的热点 |
| 增长关键词 | 可比周期内的主题变化、增长持续性和对应内容 | 识别刚开始增长或持续增长的方向 |

**预期效果**：AI 能研究“亲子露营近一个月有哪些变化，哪些方向持续增长”，结合历史表现和具体内容提出选题建议。

## 亚马逊：海外市场与营销研究

| 能力 | AI 获得什么 | 支持什么任务 |
|---|---|---|
| 商品搜索 | 商品当前信息及已记录的历史价格、卖点等信息 | 回看商品定位与调整过程 |
| 竞品对比 | 同类商品在相同历史区间的价格、榜单位置、评分和评价数量 | 比较竞品变化，寻找营销切入点 |
| 用户反馈 | 不同时间段的评价及对应商品 | 研究新增反馈、反复出现的痛点和需求变化 |
| 市场变化 | 商品价格、榜单位置及评价表现的连续变化 | 识别变化发生时间与持续性，为市场判断提供依据 |

**预期效果**：AI 能研究“美国站露营灯近一个月哪些竞品调价、排名如何变化、出现了哪些新反馈”，形成有历史依据的营销建议。

以上为需求方向；亚马逊字段及历史数据的可用范围，需依据 Dataify 实际提供的 API 能力确认。

## 基本要求

- 数据每天更新，明确平台、站点、时间、币种和指标含义。
- 更新后仍能查询过去已记录的状态；支持同一对象、同一范围的跨期比较。
- 历史从实际记录开始积累，缺失日期明确标记；区分事件发生时间与首次观测时间。
- 增长、回落等判断需有可比观测依据；累计指标与周期增量分开，时间上的同时变化不直接解释为因果关系。
- 分析依据能追溯到具体内容、商品或评价。
- 数据不足时明确说明；样本数量不等于全平台热度，榜单位置和评价数量不等于销量。

**让 AI 获得有时间跨度的事实，能够回溯、比较和识别变化。**
