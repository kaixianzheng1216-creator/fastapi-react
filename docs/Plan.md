# 数据中台首版计划

**每日积累数据，通过 MCP 向 AI 提供内容、市场信息及可追溯的历史变化。** 接入现有后台，平台在子模块内选择。

## 一、内容运营

首版接入小红书，通过 [JustOneAPI](https://docs.justoneapi.com/zh/) 获取内容及互动数据。该平台提供社交媒体、电商数据接口。

### 1. 平台榜单（已有）

保留现有功能。

### 2. 内容搜索（首版）

AI 查询已入库内容，获得标题、可获取的正文、来源、发布时间和互动数据，并可查询单条内容的历史记录。

- 条件：关键词匹配标题、正文，发布时间范围；不提供内容分类筛选。
- 排序：发布时间、最新已记录的点赞数、收藏数或评论数降序，默认最新发布。
- 分页：默认 20 条，支持继续获取。搜索不触发外部采集。

### 3. 热门内容（首版）

AI 获取跟踪样本内互动较高或增长较快的内容。

- 按点赞、收藏、评论分别排序，不做综合热度分。
- 支持累计值、近 1 天和近 7 天增量。
- 返回起止数值、实际观测日期和来源；缺少有效起止记录时不输出增量。

### 4. 热门关键词（后续）

AI 获取跟踪关键词的互动表现、历史变化及关联内容。采样口径验证后开放，不用搜索返回条数代表热度。

### 5. 增长关键词（后续）

AI 获取可比周期内增长较快的关键词及对应内容。比较口径验证后开放，不把新增样本带来的总量上涨当作增长。

### 小红书数据范围

每日围绕 **6 组、30 个关键词**发现新内容，并更新跟踪范围内已有内容的互动数据。

| 分组 | 关键词 |
|---|---|
| 美妆个护 | 护肤、彩妆、洗护、防晒、香水 |
| 服饰穿搭 | 穿搭、女装、鞋子、包包、配饰 |
| 美食饮品 | 美食、咖啡、烘焙、茶饮、零食 |
| 母婴育儿 | 母婴、育儿、辅食、孕期、早教 |
| 家居家装 | 装修、家居、收纳、家具、家电 |
| 运动户外 | 健身、跑步、徒步、露营、骑行 |

分组只组织关键词，不代表内容分类；同一内容去重保存。不承诺全文或音视频解析。

## 二、海外营销（后续）

计划接入亚马逊，通过 [Dataify](https://www.dataify.com/products/scrapers/store/amazon_product_by-asin) 获取商品数据。该平台提供网页、搜索引擎及电商数据采集。

### 1. 商品搜索

AI 查询已入库商品，获取商品信息、价格、卖点及已记录的历史。

### 2. 竞品对比

AI 比较同站点、同类商品的价格、类目排名、评分和评价数量。

### 3. 用户反馈

AI 获取评价内容、发布时间及对应商品。首次采到的旧评价不算新发布反馈。

### 4. 市场变化

AI 获取同一商品价格、排名和评价数量的历史变化。跨期比较统一站点、变体、报价、币种和榜单类别。

### 亚马逊数据范围

先限定一个站点、一个品类，用关键词或类别链接发现商品，按站点和 ASIN 持续跟踪。历史由我们积累，未确认直接查询历史区间的接口。

Dataify 官方页面已列出的条件如下，分属不同工具，尚未实测：

| 工具 | 条件 |
|---|---|
| 商品列表 | 关键词、站点域名、翻页 |
| 关键词商品详情 | 关键词、翻页、最低价、最高价 |
| 关键词或品牌采集 | 关键词、品牌、翻页 |
| 类别采集 | 类别页面 URL |
| 指定商品查询 | ASIN 或商品 URL |

字段完整率、站点覆盖和翻页限制经试采确认后确定交付范围。

## 三、首版边界与验收

**只交付小红书内容搜索、热门内容及对应 MCP 查询能力。** 关键词趋势、海外营销留到后续；不做达人业务、评论正文分析、AI 分类与报告、项目管理、监控告警、数据导出或独立大屏。

- 历史从采集开始，保留每日记录；不补过去，不做小时级跟踪。缺失不当作零，排名仅代表跟踪样本。
- 先试采验证完整度、持续取数、成功率和费用，再确定每日预算、每词上限、跟踪数量与期限。到期停止更新，保留历史。
- 验收：AI 能查询“已跟踪的露营内容中，近 7 天点赞增加最多的是哪些”，返回内容、前后数值、增量、日期和来源；记录不足时明确说明。
